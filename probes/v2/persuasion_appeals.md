# persuasion_appeals
- Source: Persuasion for Good (Wang, Shi, Kim, Oh, Yang, Zhang, Yu; ACL 2019), https://gitlab.com/ucdavisnlp/persuasionforgood, file data/AnnotatedData/300_dialog.xlsx (300 annotated dialogues), scheme data/persuader_scheme.docx. Paper: https://arxiv.org/abs/1906.06725
- Licence: Apache-2.0 (repository LICENSE). Retrieved 2026-09-21.
- Citation: Wang et al. 2019, "Persuasion for Good: Towards a Personalized Persuasive Dialogue System for Social Good", ACL 2019 (arXiv:1906.06725).
- Task: choice over 7 labels; state = one persuader sentence (no context). Criteria paraphrase the persuader annotation scheme definitions (credibility-appeal, emotion-appeal, logical-appeal, personal-story, foot-in-the-door, self-modeling [the scheme text writes "self-modelling"; the data uses "self-modeling"]).
- Sampling (build_persuasion_appeals.py, seed 20260921): persuader units (Role 0) with er_label_1; drop units with a second label, exact duplicates, length outside 25-400 chars (none class: 3-400); 20 per class = 140 items. Pool sizes: credibility 984, emotion 318, logical 436, personal-story 141, FITD 136, self-modeling 139, none 996.
- IMPORTANT deviation: every persuader unit in the annotated data has a label, so there are no "unlabelled" persuader utterances. The "none" class = units labelled with a non-strategy dialog act (greeting, thank, acknowledgement, closing, you-are-welcome, off-task, praise-user, comment-partner). The original label is in provenance.notes. Units labelled "other" and donation/inquiry acts (proposition-of-donation, donation-information, inquiries) were excluded from all classes.
- Caveats: labels are single-sentence, annotated in dialogue context, and the sentence is shown without context, so some are ambiguous or noisy (e.g. short fragments labelled self-modeling or personal-story). Crowd-worker dialogues; label noise is inherent. Foot-in-the-door has a documented exception (only small-donation asks).
- Contamination: public since 2019 on GitLab/ConvoKit; possibly in model training data.
