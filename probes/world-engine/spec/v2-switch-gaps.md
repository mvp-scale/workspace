# World Engine v2 switch: what is done and what is still keyed to v1

Switch: `WE_RULES=rules_v2` (default `rules` = v1), read once in `persona/rules.py` and honoured by every loader (`rules.load`, `load_opt`, `exists`, `dial_resources`, `topic_resources`). Start a v2 engine: `WE_RULES=rules_v2 ./service.sh start world --port 8132`. v1 numbers are unchanged (3 request digests and /graph identical before and after; `tests/test_impact.py` passes).

Vocabulary: topics, conditions, person states, decisions, resources, groups, places.

## Done (id-driven code)
| Item | Where |
|---|---|
| One reader of the ruleset choice; ruleset-specific tables optional (`load_opt`); tables keyed by size level, mode or story type (`impact_levels`, `impact_modes`, `type_weights`) fall back to v1's copy | `persona/rules.py` |
| Condition -> condition ties from `dial_ties.csv`: an applied change adds strength x amount to the target condition at the same place one tick later, no noise, not re-sent along the place channels, same 0.002 gate, at most 3 ties in a row, decays with the rest. No file = old behaviour exactly | `engine2.py`, test `tests/test_ties.py` |
| Topic -> resource join by id, derived from each condition's resource (`dials.csv resource_id`, or v1's `dial_resources.csv`); the domains `resources` column is used only when no condition-resource link exists (v1 keeps its name column, matched to ids) | `rules.topic_resources`, `world_service2.graph_info`, `exposure` |
| Condition / state / decision resource links, stakes, phrases read from the active folder; `up_means` text derived (`(bad)` = strain, `(good...)` = build, `(neutral)` = no pressure) | `world_service2.py`, `rules.dial_resources` |
| Person states with no start recipe start neutral (3.0 = no effect on any decision) instead of failing | `world_pop.py`, `engine.py` |
| Saved readings and segment exposure rows naming a condition the ruleset lacks are skipped | `world_service2.reset`, `setup_segments` |
| Unplaced-story log and news bank / cache files get a per-ruleset name (`unplaced_rules_v2.jsonl`, `bank_rules_v2.json`, `classified_rules_v2.jsonl`) so v1 files are never overwritten; a bank classified under v2 carries topic ids directly | `world_service2.py`, `classify_news_bank.py` |
| `audience.py` (v0 service) reads the active folder for its rules hash | `audience.py` |

Placeholder used (a code default, not data): when `decision_stakes.csv` is absent, every decision counts as 3/5. v2 now has the file, so this applies only to a ruleset without one.

## v2 end-to-end check (statement-form banks, written after `.banks_statements_ready`)
Boot: 300,005 people, 100 countries, 8 audiences, 19 events, about 3 s. Eight stories, top decision / top resource:
rate cut: spend / housing_stock; pandemic: health_action / population_health; war: travel / population; heat wave: spend / primary_energy; strike: travel / built_infrastructure; phone launch: study_train / computing_capacity; school reform: no condition moved (all 0.0) / none; data breach: travel / computing_capacity.
4 distinct top decisions (spend 2, travel 3, health_action 1, study_train 1; the school reform ties at 0) and 7 distinct top resources in 8. The decisions still lean on spend and travel; a story that moves no condition (school reform) shows an all-zero ranking.
