Vector walkthrough: from text to a yes/no answer, every step

Two real test sentences that are both exactly "Yes.". People labelled one as agreeing to donate and the other as answering a small-talk question. Same words, opposite answers, so only the context can separate them. We follow both through the CPU classifier: tokens → numbers → one averaged vector → a map of all 248 training vectors → the trained head → a probability. Every number is real, read from demo/mockups/vector-walkthrough.json (built by probes/vector_walkthrough.py from the same vectors the state-depth test used). Nothing on this page calls a model.

Encoder

0 · The two sentences and their context

This is the S2 state (Situation + Task + the sentence) for each. The question is the 'agree' question: does the speaker agree to donate?

1 · Words become tokens, tokens become numbers

The encoder splits text into tokens and gives each token a list of numbers (one row below, one coloured cell per number; blue = negative, orange = positive). Hover a cell for its value.

2 · The whole input becomes ONE vector: the average of every token row

Below is the full S3 input for the first "Yes." (Situation + Task + Action + sentence): one row per token, the sentence's own rows marked in the left margin. The encoder adds every row up, divides by the number of rows, and scales the result to length 1. That single row is all the classifier ever sees.

3 · Where every training example lands

All 248 training vectors, flattened from numbers to 2 (PCA: the two directions along which these vectors differ most). Orange = people said "agrees to donate", grey = everything else. The two "Yes." sentences are the ringed dots. All four panels use the same scale, so if the cloud shrinks, the vectors really did get closer together.

4 · The head: one weight per number, add up, squash to a probability

The trained head for 'agree' is a weight for each of the numbers plus a bias. Score = Σ weightᵢ × numberᵢ + bias; probability = 1 / (1 + e−score); above 50% means "yes, agrees". Rows: the head's weights, then for each "Yes." its vector and the products weight × number (what each number contributes). Pick which input the head was trained on.
