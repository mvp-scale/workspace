Call monitor: four mock-ups

MOCK-UPS. They simulate a live call with scripted playback. No audio, no speech-to-text and no model calls; every tag is scripted. Apollo 13 is a real NASA transcript; every other script is invented for layout. Open the files directly, or serve demo/mockups/ with any static server.
1 · MEETING

Live captions with a margin

Reads like live captioning. Each line gets short-code tags in a side margin and highlights in the text. Add your own watch item in a sentence.
2 · SALES / SUPPORT

Call cockpit

Waveform, chat-style transcript, live cue cards, a "captured so far" sheet and pre-wired playbooks you can switch between.
3 · 911 / TRIAGE

Intake board

Each thing you want pulled out is a slot that fills as it is heard; empty slots show what is still worth asking. Attention level on top.
4 · LAB

Pipeline lab

Audio, speech-to-text, window and models as a visible pipeline. Choose the trailing window and cadence; compare local models with the hosted one side by side, with lag.
