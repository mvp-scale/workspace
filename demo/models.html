How they work

Nine models, four techniques. This page starts from what a typed decision model is, builds up the handful of ideas every one of them relies on, and then shows the trick that sets each family apart. Diagram numbers are illustrative; model facts come from each model's own repository or card, and where something isn't published we say so.

Model codes

Every model has a code of at most six characters: family letters plus a size. B means billions of parameters and H means hundreds of millions, so KEV4B is a 4 billion parameter model and LAYA4H one of about 400 million. The table shows what is loaded in memory right now.

The big picture

A decision model reads a situation and a question with fixed options, and returns a probability for every option. It never writes prose, so software can act on the numbers directly.
