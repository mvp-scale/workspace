Technique signals, not verdicts. Probabilities, not reasons; accuracy shown per detector. Read the caveats

Models return probabilities, not written reasons, so the only "why" this page can give is the evidence: the exact trailing window scored at that moment and how the score moved. A high reading means the wording resembles what a detector was validated on, not that anyone intended anything. Each detector's measured accuracy is shown beside it; some are weak or near chance for small models, and the threat set has label noise. Documented events come from cited sources, not from us. The window study's labels belong to whole dialogues and are not localised to any turn. The windows, checkpoints and gates are composed here in page code; each model call is one independent typed question set.
