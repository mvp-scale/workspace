## What we are doing
Building the **knowledge pipeline**: a factory that turns short content (news headline + description now) into small CPU "experts" answering many questions in one pass (under 50 ms per item, one CPU thread, no API or GPU at serving). Project: `knowledge_pipeline/projects/world-state/`. Long-term vision (owner): many small CPU experts per document type behind a router, stacked like a mixture of experts. Expert 1 = news. No human gold, ever: truth is layered agreement (code, statistics, trained student, LLM teachers as voters), always reported as "agreement", never accuracy.
